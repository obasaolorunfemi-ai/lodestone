- `netlify`, `cloudflare`, `cloudflareworkers`, `vercel`, `render`, `openrouter`, `openai`, `anthropic`, `google`, `googlegemini`, `mistralai`, `ollama`, `nvidia` (.svg): from the [Simple Icons](https://simpleicons.org) set (CC0), drawn inline in the text colour by `build.mjs`.
