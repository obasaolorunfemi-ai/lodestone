# Code of conduct

This project is for people who build small tools on small budgets, often under real constraints. Everyone taking part is expected to:

- Be kind, and assume good faith. Disagree with the idea, not the person.
- Be specific. Say what you saw, what you expected and what you tried.
- Make room. Do not mock a question, a language, an accent, a country or a budget.
- Not harass anyone: no insults, threats, unwelcome attention, or sharing of someone's private information.

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block someone who keeps breaking them.

To report a problem, open a private security advisory on the Security tab of the GitHub repository (https://github.com/obasaolorunfemi-ai/lodestone/security/advisories/new) and say it is a conduct report. Only the maintainers can read it.

This text is short on purpose. If you want the longer, widely used version, the Contributor Covenant 2.1 (https://www.contributor-covenant.org/version/2/1/code_of_conduct/) says the same things in more detail and applies here as well where this text is silent.
